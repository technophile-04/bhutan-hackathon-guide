# bhutan bootcamp — submission briefing

a 4-slide deck for the speedrun ethereum bhutan bootcamp (17 may 2026).
covers hackathon rules, what a winning demo looks like, an atlas of
resources, and the mentor lineup.

## run locally

just open `index.html` in a browser, or:

```bash
npx serve .
```

## deck controls

- `← →` / `pgup pgdn` / `space` — navigate
- `home` / `end` — first / last
- number keys — jump to slide
- `r` — reset to slide 1
- `print → save as pdf` — clean one-page-per-slide export

## design source

authored at [claude.ai/design](https://claude.ai/design) and exported as
static html/css/js. fixed 1920×1080 canvas, auto-scaled by the
`<deck-stage>` web component (see `deck-stage.js`).
